# 数据库字典

> 适用范围：`admin-backend` 全部表结构（Flyway 管理，脚本见 `admin-backend/src/main/resources/db/migration`）。
> 字段说明以 `V1__init_schema.sql` 的逐字段注释为准（唯一维护点），本文为便于查阅的整理版本。

## 1. 通用约定

| 约定 | 说明 |
|---|---|
| 主键 | `BIGINT`，由 MyBatis-Plus 雪花算法生成，**禁止数据库自增**（便于后续分库分表） |
| 关联 | 逻辑外键，无数据库外键约束；关联完整性由应用层维护 |
| 时间 | 统一 `TIMESTAMP`，由应用层写入（MyBatis-Plus 自动填充），不使用数据库方言函数 |
| 状态/布尔 | 统一 `INTEGER`，如 `status 0=正常 1=停用`、`deleted 0=未删除 1=已删除` |
| 删除 | 业务数据一律**逻辑删除**（`deleted`），禁止物理删除 |
| 审计字段 | `create_by / create_time / update_by / update_time` 由应用层填充 |
| 字段注释 | 以 `--` 行注释写在 DDL 字段右侧（SQLite 不支持 `COMMENT`，这是跨库唯一可行方式） |

**注释落库（生产）**：切换 MySQL / PostgreSQL 后，执行 `admin-backend/src/main/resources/db/comments/` 下对应脚本，即可把表/字段描述写入数据库元数据（`SHOW FULL COLUMNS` / `\d+` 可见）。

## 2. 表清单

| 表 | 用途 | 关键字段 |
|---|---|---|
| `sys_user` | 用户（账号主体） | username、password、status、theme、dept_id |
| `sys_role` | 角色（权限集合） | role_name、role_key、status |
| `sys_menu` | 菜单与按钮权限 | parent_id、menu_type、path、component、permission、visible |
| `sys_user_role` | 用户-角色关联 | user_id、role_id |
| `sys_role_menu` | 角色-菜单关联 | role_id、menu_id |
| `sys_dept` | 部门（树形组织） | parent_id、dept_name、leader、status |
| `sys_login_log` | 登录审计日志 | username、ip、browser、os、status |
| `sys_token_blacklist` | 令牌黑名单 | jti、token_type、user_id、expire_time |

## 3. 表结构

### 3.1 sys_user（用户表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键（雪花 ID） |
| username | VARCHAR(64) | 登录账号；唯一性由应用层校验（逻辑删除后同名可重建） |
| password | VARCHAR(128) | BCrypt 哈希，明文永不上库 |
| nickname | VARCHAR(64) | 昵称 |
| email | VARCHAR(128) | 邮箱（列表脱敏） |
| phone | VARCHAR(32) | 手机号（列表脱敏） |
| sex | INTEGER | 0=未知 1=男 2=女 |
| avatar | VARCHAR(255) | 头像地址 |
| status | INTEGER | 0=正常 1=停用（停用不可登录） |
| theme | VARCHAR(10) | 主题偏好：light / dark / auto，跨设备同步 |
| dept_id | BIGINT | 所属部门，0=未分配 |
| login_ip | VARCHAR(64) | 最近登录 IP |
| login_date | TIMESTAMP | 最近登录时间 |
| remark | VARCHAR(500) | 备注 |
| create_by / create_time | BIGINT / TIMESTAMP | 创建人与创建时间 |
| update_by / update_time | BIGINT / TIMESTAMP | 更新人与更新时间 |
| deleted | INTEGER | 0=未删除 1=已删除 |

索引：`idx_user_username`（账号检索）、`idx_user_status`（状态筛选）、`idx_user_dept`（部门筛选）

### 3.2 sys_role（角色表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| role_name | VARCHAR(64) | 角色名称（如"普通管理员"） |
| role_key | VARCHAR(64) | 角色权限字符（如 admin / common） |
| sort | INTEGER | 显示排序，越小越靠前 |
| status | INTEGER | 0=正常 1=停用 |
| remark | VARCHAR(500) | 备注 |
| create_by / create_time / update_by / update_time | — | 审计字段 |
| deleted | INTEGER | 逻辑删除 |

索引：`idx_role_key`、`idx_role_status`

### 3.3 sys_menu（菜单/权限表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| parent_id | BIGINT | 父菜单 ID，0=顶级 |
| menu_name | VARCHAR(64) | 菜单名称（同时作为路由标题） |
| menu_type | INTEGER | 1=目录 2=菜单 3=按钮 |
| path | VARCHAR(200) | 路由地址（按钮为空） |
| component | VARCHAR(255) | 前端组件路径（相对 views；目录为 Layout） |
| permission | VARCHAR(100) | 权限标识（如 `system:user:add`），后端 `@PreAuthorize` 校验 |
| icon | VARCHAR(100) | Element Plus 图标名 |
| sort | INTEGER | 显示排序 |
| visible | INTEGER | **1=显示 0=隐藏**（注意与部分系统相反，隐藏节点不进侧边栏） |
| status | INTEGER | 0=正常 1=停用 |
| remark | VARCHAR(500) | 备注 |
| create_by / create_time / update_by / update_time | — | 审计字段 |
| deleted | INTEGER | 逻辑删除 |

索引：`idx_menu_parent`（构建菜单树）、`idx_menu_permission`（鉴权与授权查询）

### 3.4 sys_user_role（用户-角色关联表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| user_id | BIGINT | 用户 ID（逻辑外键 → sys_user.id） |
| role_id | BIGINT | 角色 ID（逻辑外键 → sys_role.id） |
| create_by / create_time | — | 授权人与授权时间 |

索引：`uk_user_role(user_id, role_id)` 唯一，防重复授权；`idx_ur_role` 按角色反查用户

### 3.5 sys_role_menu（角色-菜单关联表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| role_id | BIGINT | 角色 ID |
| menu_id | BIGINT | 菜单 ID（含按钮节点） |
| create_by / create_time | — | 授权人与授权时间 |

索引：`uk_role_menu(role_id, menu_id)` 唯一；`idx_rm_menu` 按菜单反查角色

### 3.6 sys_dept（部门表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| parent_id | BIGINT | 父部门 ID，0=顶级 |
| dept_name | VARCHAR(64) | 部门名称 |
| sort | INTEGER | 显示排序 |
| leader | VARCHAR(64) | 负责人 |
| phone / email | VARCHAR(32) / VARCHAR(128) | 联系电话 / 邮箱 |
| status | INTEGER | 0=正常 1=停用 |
| remark | VARCHAR(500) | 备注 |
| create_by / create_time / update_by / update_time | — | 审计字段 |
| deleted | INTEGER | 逻辑删除 |

索引：`idx_dept_parent`（构建部门树）

### 3.7 sys_login_log（登录日志表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| username | VARCHAR(64) | 登录账号 |
| ip | VARCHAR(64) | 登录 IP |
| location | VARCHAR(255) | 登录地点（IP 归属地，未接入三方库时为空） |
| browser / os | VARCHAR(128) | 浏览器 / 操作系统（由 User-Agent 解析） |
| status | INTEGER | 0=成功 1=失败 |
| msg | VARCHAR(500) | 提示信息（失败原因） |
| login_time | TIMESTAMP | 登录时间 |

索引：`idx_login_time`（倒序展示）、`idx_login_username`（按账号追溯）

### 3.8 sys_token_blacklist（令牌黑名单表）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | BIGINT | 主键 |
| jti | VARCHAR(64) | 令牌唯一标识（JWT 的 `jti` 声明） |
| token_type | VARCHAR(16) | access / refresh |
| user_id | BIGINT | 所属用户（便于按用户批量清理） |
| expire_time | TIMESTAMP | 令牌原过期时间（便于清理已失效记录） |
| create_time | TIMESTAMP | 加入黑名单的时间 |

索引：`uk_blacklist_jti` 唯一；`idx_blacklist_expire` 按过期时间清理

## 4. 枚举取值速查

| 字段 | 取值 |
|---|---|
| `sys_user.sex` | 0=未知 1=男 2=女 |
| `sys_user.status` / `sys_role.status` / `sys_menu.status` / `sys_dept.status` | 0=正常 1=停用 |
| `sys_user.theme` | light / dark / auto |
| `sys_menu.menu_type` | 1=目录 2=菜单 3=按钮 |
| `sys_menu.visible` | 1=显示 0=隐藏 |
| `deleted` | 0=未删除 1=已删除 |
| `sys_login_log.status` | 0=成功 1=失败 |
| `sys_token_blacklist.token_type` | access / refresh |
